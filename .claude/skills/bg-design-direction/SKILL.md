# 배경 디자인 디렉션 (WebGL 도메인-워프 FBM)

프리미엄 에디토리얼 테마(`src/pages/designs/premium.astro`)의 풀블리드 고정 배경 작업 절차.
**단일 소스는 `.claude/design/` 문서다.** 값을 지어내지 말고 항상 이 문서를 먼저 읽고, 바뀌면 문서부터 고친다.

## 먼저 읽을 것 (순서대로)
1. `.claude/design/00-brief.md` — 무엇을·왜 (아트디렉션, non-AI, §11 셰이더 원칙)
2. `.claude/design/01-tokens.md` — 팔레트·그레인·비네트 + **스크롤→파라미터 매핑 표**
3. `.claude/design/02-shader-spec.md` — 도메인-워프 FBM 유니폼 계약
4. `.claude/design/03-guards-fallback.md` — DPR캡·탭숨김·reduced-motion·CSS폴백·모바일
5. `.claude/design/05-hero-interactions.md` — 콘텐츠 스크롤 앤 액션(패럴랙스·진입·스냅/핀·포인터+스크롤)
6. `.claude/design/04-qa-acceptance.md` — 릴리즈 게이트(§A~G 배경, §H 인터랙션)

## 타협 불가 원칙
- **제네릭 파티클 금지** (§11). 별·먼지·둥둥 뜨는 점 금지. 표현은 셰이더 필드(도메인 워프)뿐.
- **라이트 프리미엄 · non-AI.** 자동 다크 금지. 그레인·비네트로 아날로그 인쇄 질감.
- **팔레트 고정.** `01-tokens.md` 색 밖으로 나가지 않는다(브랜드 `premium.astro`에서 파생).
- **가독성 최우선.** 배경이 본문 WCAG AA 대비를 깨면 안 된다.
- **미세함.** 포인터 패럴랙스 ±1.5% 이내, 느린 드리프트. 과함 = 싸구려.

## 작업별 절차

### 스펙 작성/수정
- 의도가 바뀌면 `00`~`03`을 고친다. 매핑 값은 `01`의 표, 유니폼은 `02`가 정본.
- 새 값은 "시작점"으로 두고 실화면 튜닝 여지를 남기되, 튜닝 결과를 다시 문서에 반영.

### 구현 리뷰
- 시안/구현이 나오면 `04-qa-acceptance.md` §A~H를 순서대로 대조.
- 브레이크포인트 `320/375/768/1024/1440/1920` × 스크롤 `s=0/0.5/1` × 상태 `정상/reduced-motion/WebGL-off` 스크린샷.
- **배경**(셰이더·폴백·성능): `bg-design-reviewer` 에이전트 · 실행형 `/bg-qa`(§A~G).
- **콘텐츠 인터랙션**(패럴랙스·진입·스냅/핀·포인터+스크롤): `hero-interaction-reviewer` 에이전트 · 실행형 `/interaction-qa`(§H).

### 레퍼런스 수집
- `/design-refs` 절차. AI 생성 이미지 금지 — 마블링/먹/대리석/프리미엄 인쇄 실물 소스.

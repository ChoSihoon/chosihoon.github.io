# /design-refs — 레퍼런스 수집

프리미엄 배경의 무드를 실물·전통 소스에서 모은다. **AI 생성 이미지 금지**(non-AI 룩이 목표).

## 먼저
`.claude/design/00-brief.md`의 "레퍼런스 방향"과 `01-tokens.md` 팔레트를 읽는다. 수집은 이 방향 안에서.

## 수집 카테고리 (각 2~3점)
1. **마블링 페이퍼** — Suminagashi(먹 마블링), Turkish Ebru, 고서 엔드페이퍼.
2. **먹 번짐 / sumi-e** — 종이에 번지는 잉크, 여백의 긴장.
3. **대리석 결** — 실제 대리석 단면의 정맥(vein) 패턴.
4. **프리미엄 인쇄** — 듀오톤/특수 잉크, 리소그래프 그레인, 페이퍼 텍스처.
5. **절제된 셰이더 아트** — 도메인 워프 필드·느린 유체(파티클 아님). 참고만, 팔레트는 우리 것.

## 판정 기준 (모으기 전 자문)
- 라이트/웜인가? (어두운·네온·AI 그라디언트는 탈락)
- 잉크·마블·종이 결의 아날로그 질감이 있는가?
- 우리 팔레트(웜 페이퍼 ↔ 딥 잉크블루 + 웜 샌드)로 번역 가능한가?
- 파티클/별/블롭에 의존하지 않는가? (§11)

## 산출물
- `.claude/design/refs/` 에 8~12점. 각 항목에 캡션:
  `출처 · 왜 골랐나(무드/색/질감) · 우리 배경의 어느 파라미터에 매핑되나(왜곡/색온도/그레인/비네트)`.
- 정리 후 `00-brief.md`에서 참조할 수 있게 목록 한 줄 요약.

## 실행 메모
웹 검색이 가능하면 위 카테고리 키워드로 실물 이미지 소스(미술관·아카이브·인쇄 스튜디오)를 우선 탐색한다.
저작권/출처를 캡션에 남긴다. 다운로드가 어려우면 링크 + 스크린샷 캡션으로 대체한다.

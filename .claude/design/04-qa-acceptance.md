# 04 · QA 수용 기준 (배경 릴리즈 게이트)

> 전 항목 통과해야 머지. `bg-design-reviewer` 에이전트 또는 `/bg-qa`가 이 목록으로 점검한다.
> 근거 문서: 아트디렉션 `00` · 토큰 `01` · 셰이더 `02` · 가드 `03`.

## A. 아트디렉션 정합
- [ ] 흐르는 잉크/마블 듀오톤으로 읽힌다(파티클/별/블롭 아님 — §11).
- [ ] 라이트 프리미엄. 어둡거나 채도 높은 "AI 그라디언트" 인상이 아니다.
- [ ] 그레인·비네트가 있어 아날로그 인쇄 질감이 난다(non-AI).
- [ ] `sand` 웜 정맥이 마블 경계에 얇게 존재(면적 ≤ 12%).
- [ ] 색이 `01-tokens.md` 팔레트를 벗어나지 않는다.

## B. 스크롤 연출 (핵심 체감)
- [ ] 상단→하단으로 **왜곡량 증가**가 느껴진다(`uWarp 0.35→0.85`).
- [ ] 상단 warm → 하단 cool로 **색온도가 식는다**(`uColorTemp 0.72→0.18`).
- [ ] 하단으로 갈수록 **대비가 깊어진다**(`uContrast 0.92→1.25`).
- [ ] 앵커 점프/빠른 스크롤에도 값이 튀지 않는다(damping 동작).
- [ ] 포인터 미세 패럴랙스가 있으나 어지럽지 않다(±1.5% 이내).

## C. 접근성 (`03` 가드)
- [ ] `prefers-reduced-motion: reduce`에서 **움직임 완전 정지**(정물 프레임 유지, 색/구도 보존).
- [ ] reduced-motion에서 포인터 패럴랙스·스크롤 왜곡도 정지.
- [ ] 배경 위 본문 대비 **WCAG AA 통과**(본문 ≥ 4.5:1, 대형 텍스트 ≥ 3:1) — 히어로/각 섹션 텍스트 실측.
- [ ] 캔버스 `aria-hidden` · `pointer-events:none` · 포커스 트랩 없음.

## D. 폴백 (`03`)
- [ ] WebGL 비활성(플래그로 강제)에서 CSS 폴백이 프리미엄 정물화로 뜬다(깨진 흰 화면 아님).
- [ ] `webglcontextlost` 시 폴백으로 안전 전환.
- [ ] 폴백에서도 팔레트·비네트·그레인 인상이 유지된다.

## E. 성능 (`03` · CWV)
- [ ] DPR 캡 ≤ 1.75 적용(레티나에서 확인).
- [ ] 탭 숨김 시 rAF 정지(다른 탭 전환 후 CPU/GPU idle 확인).
- [ ] 모바일(≤ 640) 다운스케일 + octaves 감소 적용, 프레임 안정.
- [ ] LCP < 2.5s · CLS < 0.1(배경발 레이아웃 시프트 0) · INP < 200ms.
- [ ] JS 예산: 배경 추가로 랜딩 JS(gzip) 급증 없는지 — three.js는 동적 import/최소 번들.

## F. 반응형 (오버플로 0)
- [ ] 320 / 375 / 768 / 1024 / 1440 / 1920 에서 가로 스크롤 없음, 배경 풀블리드.
- [ ] 초광폭·초협폭에서 노이즈 스케일이 뭉개지거나 반복 이음매가 보이지 않는다.
- [ ] 주소창 접힘(모바일 100vh 이슈)에서 배경 하단 잘림/흰 띠 없음(`dvh`/fixed 확인).

## G. 크로스 브라우저
- [ ] Chrome · Firefox · Safari 에서 렌더·스크롤 연동·폴백 동작 일치.
- [ ] Safari에서 색공간(P3/sRGB) 튀지 않음, 그레인 밴딩 없음.

## H. 히어로 인터랙션 (콘텐츠 레이어 — 근거 `05-hero-interactions.md`)
> §A~G는 배경(WebGL) 게이트, §H는 그 위 콘텐츠의 스크롤 앤 액션. `/interaction-qa`가 이 섹션을 담당.
- [ ] **① 콘텐츠 패럴랙스**: 심부/타이틀/본문이 서로 다른 속도로 움직여 입체감(계수 `05` 표와 일치), 겹침·빈틈 없음.
- [ ] **② 스크롤 진입**: 진입 시 `translateY(24px)+fade`, stagger `80ms`, once 재생(역방향 반복 없음).
- [ ] **③ 스냅/핀**: 히어로 `100dvh`(주소창 접힘에서 흰 띠 없음), 전역 강제 스냅 없음, 핀은 sticky 기반이며 스크롤을 가두지 않음.
- [ ] **④ 포인터+스크롤**: 마그네틱/틸트가 미세(±6px·±1.5° 이내), 포인터+스크롤 한 rAF 합산, damping 있음.
- [ ] **터치**: coarse 포인터(모바일)에서 포인터 효과 비활성(`hover:hover and pointer:fine`).
- [ ] **접근성**: reduced-motion에서 시차·틸트·진입 이동 전부 정지·즉시 최종 상태, 스크롤 미차단.
- [ ] **no-JS/점진 향상**: JS 미로드 시 콘텐츠가 보이는 상태(영구 `opacity:0` 아님).
- [ ] **성능**: 스크롤 리스너 1개(rAF 게이트), transform/opacity만, 스크롤 중 long task 없음, INP < 200ms.

## 리뷰 산출물
스크린샷: `{320,768,1024,1440}` × `{s=0, s=0.5, s=1}` × `{정상, reduced-motion, WebGL-off}`.
저장 위치 제안: `.claude/design/qa/<날짜>/`.

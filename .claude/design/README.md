# 디자이너 하네스 — 프리미엄 배경(WebGL 도메인-워프 FBM)

이 폴더는 프리미엄 에디토리얼 테마(`src/pages/designs/premium.astro`)의 **풀블리드 고정 배경**을
현재의 CSS orb/grid에서 **three.js 스크롤 연동 도메인-워프 FBM 노이즈**(흐르는 잉크/마블 듀오톤)로
교체하기 위한 **디자인 단일 소스**입니다. 개발 코드가 아니라 "무엇을·어떻게 보이게" 정의합니다.

## 컨셉 한 줄
라이트 프리미엄 · non-AI · 2026 — 페이지 전체에 고정된 배경 위로 콘텐츠가 흐르고,
스크롤 진행도가 왜곡량·색온도·대비를 구동해 "스크롤 영상"처럼 체감된다.
(설계 §11: **셰이더(색온도·왜곡·카메라) 기반 · 제네릭 파티클 금지**)

> **스코프 2개**: `00`~`03`은 **배경(WebGL)** 피처, `05`는 그 위 **콘텐츠 인터랙션** 레이어. `04`가 둘 다의 게이트.

## 워크플로우
1. **스펙** — `00`~`03`을 단일 소스로 확정. 값이 바뀌면 여기부터 고친다(코드가 아니라).
2. **리뷰** — 구현/시안이 나오면 `bg-design-reviewer` 에이전트 또는 `/bg-qa`로 대조.
3. **QA** — `04-qa-acceptance.md`의 게이트를 전부 통과해야 머지.

## 관련 스킬·커맨드
- 스킬: `bg-design-direction` — 배경·인터랙션을 스펙/리뷰할 때 따라야 할 절차(디자인 디렉션 허브)
- 커맨드: `/bg-qa` (배경 §A~G) · `/interaction-qa` (인터랙션 §H) · `/design-refs` (레퍼런스 수집)
- 에이전트: `bg-design-reviewer` (배경 셰이더·폴백·성능) · `hero-interaction-reviewer` (콘텐츠 스크롤 앤 액션)

## 원칙 (타협 불가)
- **제네릭 파티클/블롭 금지.** 별·먼지·둥둥 뜨는 점 형태 금지. 표현은 오직 셰이더 필드(도메인 워프).
- **라이트 우선.** 자동 다크모드 아님. 종이 질감의 밝은 프리미엄이 기본.
- **non-AI 룩.** AI 이미지 특유의 매끈한 그라디언트·플라스틱 광택 지양. 잉크·마블·종이 결.
- **콘텐츠 가독성 최우선.** 배경은 결코 본문 대비를 침해하지 않는다(`04` 대비 게이트 참조).
